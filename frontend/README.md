# واجهة دكان البرعي

React + Vite. التصميم مستوحى من أجواء دكان قطع الغيار والخردوات في مسلسل «لن أعيش في جلباب أبي».

## التشغيل

```bash
npm install
npm run dev
```

## ملفات التصميم

- `src/styles/base.css`: الألوان والخطوط والأساسيات (متغيرات `:root`).
- `src/styles/components.css`: التندة والنافبار، الأزرار، الفورم، تاجات البضاعة، الدفتر.
- `src/styles/pages.css`: واجهة المحل في الصفحة الرئيسية، التفاصيل، الفاتورة.
- `src/components/PartIcon.jsx`: أيقونات القطع (ترس، صامولة، مسمار، زنبرك، قفل، شاكوش، شكارة).

الخطوط (Lalezar و Aref Ruqaa و Tajawal) بتتحمل من Google Fonts في `index.html`.
